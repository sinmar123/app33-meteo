🎯 COMANDI RAPIDI

  python demo.py stations

Mostra criteri di sicurezza:
  python demo.py criteria

Analizza un giorno (esempio):
  python main.py --date 2024-01-15 --station GE036 \
    --station-name "GENOVA" --skip-download \
    --data-file data/esempio_dati_meteo.csv

================================================================================
📊 COSA FA IL SISTEMA
================================================================================

Analizza dati meteo e ti dice se puoi lavorare in cantiere:

INPUT:  Dati meteo di un giorno (temperatura, vento, pioggia, etc.)
OUTPUT: Report con:
        • Score sicurezza 0-100
        • Categoria (OTTIMO, BUONO, ACCETTABILE, VIETATO, etc.)
        • Avvisi specifici (vento forte, pioggia, gelo, etc.)
        • Idoneità per tipo lavoro (scavi, opere in quota, getti, etc.)

Basato su:
  - D.Lgs 81/2008 (Sicurezza Lavoro)
  - Norme Tecniche Costruzioni NTC 2018
  - Best practices ingegneristiche
