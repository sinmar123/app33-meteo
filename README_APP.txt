📱 COME FUNZIONA

1. Si apre il browser con l'interfaccia grafica

2. Nella BARRA SINISTRA:
   ├─ Scegli stazione meteo
   ├─ Scegli data
   └─ Carica file CSV (o usa esempio)

3. Nel CENTRO:
   └─ Premi pulsante "ANALIZZA"

4. Vedi RISULTATI:
   ├─ Score sicurezza (0-100)
   ├─ Si può lavorare? (SI/NO)
   ├─ Grafici colorati
   ├─ Avvisi meteo
   └─ Idoneità per ogni tipo lavoro

5. SCARICA report in PDF/CSV

🔧 PROBLEMI?

"Python non trovato"
→ Installa Python da: https://www.python.org
→ Windows: spunta "Add to PATH"!

"L'app non si apre"
→ Apri browser su: http://localhost:8501

"Errore caricamento file"
→ Verifica che CSV abbia colonne:
  temperatura, precipitazione, vento_velocita, umidita, visibilita
